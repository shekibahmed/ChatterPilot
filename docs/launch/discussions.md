# GitHub Discussions

Enable Discussions only after the repository is public (Settings, General, Features). GitHub creates
default categories; rename or replace them with the set below. Discussions are for questions and
open conversation; anything concrete (a bug, a failing export format, a use case) should move to an
issue form, and the moderator can convert a discussion into an issue.

## Proposed categories

| Category | Format | Purpose |
|---|---|---|
| Announcements | Announcement (maintainers post) | Releases, changes to the roadmap, calls for help |
| Q&A | Question and answer | Setup, the demo, catalogue files, connecting an agent |
| How you use it | Open discussion | Setups, agents and workflows people have tried; links to "Tell us how you use it" issues |
| Order words and languages | Open discussion | How orders are written in a language, region or trade, with invented examples |
| Billing tools and exports | Open discussion | Tally, ERPNext, Zoho Books, Busy, Vyapar, Marg and others: what an import needs |
| Agents and MCP | Open discussion | Using and extending ChatterPilot from Claude Code, Codex, Cursor or your own agent |
| Ideas | Open discussion | Early ideas before they are ready for the "Idea or use case" form |

Every category description should end with: "Use invented data only. Never post real chats, names,
phone numbers or prices."

## Pinned welcome post

**Title:** Welcome: what ChatterPilot is, and how to help

Welcome. ChatterPilot is an early, MIT-licensed prototype that turns WhatsApp order messages into
drafts where every value cites its source, so a person can check and accept them before anything is
exported. It runs on your own computer, has been tested only on synthetic data, and has not yet been
used by a real business, so the most useful thing you can share is how your work actually happens:
who sends orders, where they are re-typed, what goes wrong, and what you tried with the code or your
coding agent. Ask setup questions in Q&A; describe your workflow or experience with the "Tell us how
you use it" or "Idea or use case" issue forms; report problems with the "Bug report" or "Export
format, language or order words" forms; and report security problems privately as described in
SECURITY.md. Please use invented examples only and never post a real chat, customer name, phone
number or price, here or anywhere in the repository.
