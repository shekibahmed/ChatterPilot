# Code of conduct

This project follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be respectful and patient, assume good faith, and remember that many people here run
small businesses and are not software developers. Questions in any language are welcome; answers
may take longer.

Report unacceptable behaviour to the maintainer, [@shekibahmed](https://github.com/shekibahmed),
privately on GitHub. Reports are kept confidential.
