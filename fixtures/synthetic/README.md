# Synthetic fixtures

Every file here was written by hand for ChatterPilot. All people, businesses, prices, phone numbers,
order references and file names are fictional. Nothing was taken from a real chat export.

Do not add real chats, audio, screenshots or customer records, even redacted or in a private branch.

Encoding notes: exports use U+202F (narrow no-break space) before am/pm and U+200E (left-to-right mark)
before iOS system/media lines, as recent WhatsApp exports do. Edit these files with a tool that keeps
those characters.
